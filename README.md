# STL Viewer

[![Версия](https://img.shields.io/badge/version-0.5-yellow.svg)](#)
[![Python](https://img.shields.io/badge/python-3.12%2B-blue.svg)](https://www.python.org/)
[![Лицензия](https://img.shields.io/badge/license-MIT-green.svg)](#лицензия)
[![Статус](https://img.shields.io/badge/status-beta-orange.svg)](#)

Лёгкий настольный просмотрщик 3D‑моделей для Windows: STL, 3MF, OBJ, PLY и GLB.
Написан на Python + Three.js, работает в окне pywebview, не требует браузера и интернета.

> **v0.5** — первая публичная бета. Функционал ограничен просмотром и диагностикой моделей, см. раздел [«Задача проекта»](#задача-проекта).

## Возможности

- **Просмотр** моделей в форматах STL, 3MF, OBJ, PLY, GLB.
- **Орбитальная камера**: вращение (ЛКМ), панорама (ПКМ), зум (колесо).
- **Ориентация модели**: поворот по X/Y/Z на 90°, сброс к исходной ориентации.
- **Автоматическая центровка**: X = 0, Z = 0, нижняя плоскость на сетке (Y = 0).
- **Освещение**: регулировка резкости и контраста ползунками в реальном времени.
- **Режим каркаса**, **авто‑вращение**, **сетка**, **вписать в экран**, **скриншот**.
- **Диагностика модели**: число треугольников/вершин, габариты, объём,
  согласованность нормалей, предупреждения о единицах и превышении стола печати.
- **Логотип в UI** и иконка окна (на Windows) — подхватываются из папки проекта.

## Задача проекта

**STL Viewer** — первая часть более крупного проекта: **библиотеки 3D‑моделей
со встроенным просмотрщиком и системой анализа моделей**.

На текущий момент в режиме тестирования реализован **только просмотрщик**:
загрузка, отображение и базовая диагностика. Библиотека, каталогизация,
теги, поиск и расширенный анализ — в планах (см. [«Планы развития»](#планы-развития)).

## Установка и запуск из исходников

### Требования

- **Windows 10/11** (для WebView2 окна; на Linux/macOS pywebview использует
  другие бэкенды, но проект тестировался на Windows).
- **Python 3.12+** (см. [python.org](https://www.python.org/downloads/)).
- **Git** (для клонирования; необязательно, можно скачать ZIP).
- **WebView2 Runtime** — обычно уже установлен в Windows 10/11. Если окно
  открывается пустым, скачайте
  [Evergreen WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/).

### Шаги

```powershell
git clone https://github.com/SantidioEsanti/STL-Viewer.git
cd STL-Viewer

python -m venv .venv
.\.venv\Scripts\Activate.ps1

python -m pip install --upgrade pip
python -m pip install pywebview trimesh numpy
```

### Что положить в `libs/`

Проект ожидает в папке `libs/` два JS‑файла (в репозиторий не коммитятся —
слишком крупные, скачиваются отдельно):

```
libs/
  three.module.js
  addons/
    controls/
      OrbitControls.js
```

Скачать можно из npm‑пакета `three` последней версии:

- `https://unpkg.com/three/build/three.module.js`
- `https://unpkg.com/three/examples/jsm/controls/OrbitControls.js`

Положите `OrbitControls.js` в `libs/addons/controls/` — важно сохранить
именно такую структуру, на неё ссылается `importmap` в HTML.

### Запуск

```powershell
python .\STL_viwer.py
```

> **Примечание.** Если команда `python` в вашей системе указывает на другой
> интерпретатор (бывает, если в PATH есть встроенный Python от сторонних
> приложений), активируйте venv или запускайте через
> `py -3.12 .\STL_viwer.py`.

## Сборка exe

Сборка в **один файл** (`--onefile`) без консольного окна (`--windowed`).
Команда использует только базовые возможности PyInstaller и не учитывает
особенности конкретной локальной системы.

### Установка PyInstaller

```powershell
python -m pip install pyinstaller
```

### Команда сборки

```powershell
python -m PyInstaller --noconfirm --onefile --windowed ^
    --name "STL_Viewer" ^
    --icon "icon.ico" ^
    --add-data "libs;libs" ^
    --add-data "logo.png;." ^
    --add-data "icon.ico;." ^
    STL_viwer.py
```

> В **PowerShell** разделитель строк — обратный апостроф `` ` ``, в **cmd** —
> `^`. Или запишите команду одной строкой без переносов.

### Результат

```
dist/
  STL_Viewer.exe
```

Файл самодостаточен: все зависимости (Python, pywebview, trimesh, numpy,
JS‑файлы, логотип и иконка) упакованы внутрь. При первом запуске exe
распаковывает их во временную папку — старт занимает 2–5 секунд.

### Пояснение к флагам

| Флаг | Назначение |
|------|------------|
| `--onefile` | собрать всё в один `.exe` |
| `--windowed` | без консольного окна |
| `--name "STL_Viewer"` | имя итогового файла |
| `--icon "icon.ico"` | иконка exe‑файла в проводнике |
| `--add-data "libs;libs"` | Three.js + `viewer.html` во временную папку |
| `--add-data "logo.png;."` | логотип для UI |
| `--add-data "icon.ico;."` | иконка окна (устанавливается через `WM_SETICON`) |

## Поддерживаемые форматы

| Формат | Расширения | Примечание |
|--------|------------|------------|
| STL | `.stl` | бинарный и ASCII |
| 3MF | `.3mf` | сцены объединяются в одну сетку |
| OBJ | `.obj` | без материалов (только геометрия) |
| PLY | `.ply` | бинарный и ASCII |
| GLB | `.glb` | только геометрия, без текстур/анимаций |

Форматы читаются через [trimesh](https://trimesh.org/) — поддержка может
варьироваться в зависимости от версии библиотеки.

## Управление

### Камера

| Действие | Кнопка мыши |
|----------|-------------|
| Вращение | ЛКМ + перетаскивание |
| Панорама | ПКМ + перетаскивание |
| Масштаб | колесо |

### Панель инструментов

- **📂 Открыть файл** — диалог выбора модели.
- **X / Y / Z** — поворот модели на +90° вокруг соответствующей оси.
- **↺** — сброс к исходной ориентации (270° по X).
- **⤢** — вписать модель в экран.
- **⬡** — каркасный режим.
- **⟳** — авто‑вращение.
- **▦** — показать/скрыть сетку.
- **📷** — сохранить скриншот в PNG.

### Ползунки освещения

- **Резкость** — соотношение рассеянного и направленного света.
- **Контраст** — экспозиция тональной компрессии (ACES Filmic).

## Структура проекта

```
STL-Viewer/
├── STL_viwer.py           # весь код: Python-бэкенд + HTML/CSS/JS
├── apply_patch.py         # патч: логотип, иконка, WM_SETICON
├── logo.png               # логотип для UI
├── icon.ico               # иконка окна / exe
├── libs/                  # Three.js (скачивается отдельно)
│   ├── three.module.js
│   ├── addons/
│   │   └── controls/
│   │       └── OrbitControls.js
│   └── viewer.html        # генерируется при первом запуске
├── docs/                  # скриншоты
├── README.md
└── .gitignore
```
> **Примечание об имени файла.** Основной скрипт называется `STL_viwer.py`
> (буква `e` пропущена в слове `viewer`) — это историческая опечатка,
> допущенная в первой версии. Имя сохранено ради обратной совместимости
> и чтобы не ломать существующие инструкции и ярлыки. В командах запуска
> и сборки используется именно текущее написание.

Весь UI (HTML/CSS/JS) встроен в `STL_viwer.py` и записывается в
`libs/viewer.html` при старте. Это упрощает сборку в один exe и исключает
рассинхронизацию между Python и HTML.

## Диагностика моделей

После загрузки в левой панели отображается:

- **Размер файла**, время загрузки (Python + рендер отдельно).
- **Треугольники / вершины** — с разделителями разрядов.
- **Габариты** (X × Y × Z в мм).
- **Нормали** — согласованы или нет.
- **Объём** (если модель замкнута и треугольников < 500 000).

### Автоматические предупреждения

- ⚠ Непоследовательные нормали — возможны артефакты при печати.
- ⚠ Очень маленькая модель (< 0.1 мм) — проверьте единицы.
- ⚠ Модель больше типичного стола печати (> 300 мм).
- ⚠ Очень много треугольников (> 2 000 000) — медленная загрузка и печать.
